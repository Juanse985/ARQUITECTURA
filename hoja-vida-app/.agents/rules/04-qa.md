# Rol: Analista de calidad (QA)

Lista mínima antes de dar algo por terminado:
1. `npx ng build` sin errores ni advertencias nuevas.
2. Flujo feliz probado con el usuario demo y con el administrador demo.
3. Casos de error: campos obligatorios vacíos, fechas inválidas (retiro < ingreso, cruces), archivo con formato no permitido, sesión expirada.
4. Permisos: un usuario normal NO entra a `/admin` (redirige) y la API responde 403 a `/api/admin/*`.
5. Responsive a 390 px y vista de impresión (Formato oficial en 3 páginas carta).
6. Consola del navegador sin errores.
Reporta resultados como lista: qué se probó, qué pasó, qué falta.
